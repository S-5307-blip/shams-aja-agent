# وكيل واتساب (المرحلة الأولى)

## ماذا ينجز هذا الإصدار
- يستقبل رسائل العملاء عبر WhatsApp Cloud API مباشرة من Meta.
- يجهّز الرد المقترح بالذكاء الاصطناعي (Claude) حسب قواعد الوكيل المعتمدة، ويرسل لك **على واتساب** رسالة بثلاثة أزرار: موافقة وإرسال / تعديل / رفض.
- لا يُرسل أي رد للعميل دون موافقتك، **عدا** رد قصير خارج ساعات العمل (٤ م – ١١ م) مرة كل ٦ ساعات لكل عميل.
- يحوّل إليك فوراً: الشكاوى، وطلبات الخصم، والحالات المعقدة، وما ليس في معرفته.
- لا يقرأ صور الهويات والمستندات، ويوجّه العميل للبوابة الآمنة.
- يحترم كلمة «إيقاف» من العميل.
- المعرفة الحالية: 138 خدمة منشورة من ملف الكتالوج (الاسم والفئة والحالة والجهة، ومع المتطلبات والخطوات والمدة لما توفّرت). لا أسعار فيها، وتُضاف لاحقاً. الأسعار المرجعية الأربعة الموجودة في الملف محفوظة في reference-prices.json وغير محمّلة في الوكيل.
- **غير مشمول هنا (المرحلة التالية):** الرسائل التسويقية (متابعة المترددين، تذكيرات التجديد، الحملات، طلب التقييم). ملف القوالب جاهز للتقديم في `templates/meta-templates.json`.

## ما تحتاجه (لا ترسل أي مفتاح في المحادثة أبداً)
| العنصر | من أين |
|---|---|
| مفتاح Claude API | console.anthropic.com ← أنشئ حساباً، اشحن رصيداً، ثم API Keys |
| رمز الوصول الدائم (Access Token) | Meta Business ← System Users ← أنشئ مستخدم نظام ← Generate token بصلاحية `whatsapp_business_messaging` و `whatsapp_business_management` |
| Phone Number ID | لوحة تطبيقك في developers.facebook.com ← WhatsApp ← API Setup |
| App Secret | App settings ← Basic |
| رقم المالك | رقم جوالك الشخصي (يجب أن يختلف عن رقم واتساب المكتب 966576038773) بصيغة 9665XXXXXXXX |

## النشر على Railway
1. ارفع هذا المجلد إلى مستودع GitHub خاص، ثم في Railway: New Project ← Deploy from GitHub.
2. أضف **Volume** واربطه على المسار `/data` (لحفظ المحادثات).
3. في Variables أضف القيم الموجودة في `.env.example` (وليس ملف .env نفسه).
4. من Settings ← Networking ← Generate Domain، وسيعطيك رابطاً مثل `https://xxxx.up.railway.app`.
5. في Meta: WhatsApp ← Configuration ← Webhook:
   - Callback URL: `https://xxxx.up.railway.app/webhook`
   - Verify token: نفس قيمة `WA_VERIFY_TOKEN`
   - اشترك في الحقل **messages**.
6. تأكد من رقم إصدار Graph API الحالي في لوحة Meta وضعه في `GRAPH_API_VERSION` إن اختلف.

## التجربة قبل الإطلاق
1. من جوالك الشخصي (رقم المالك) أرسل أي رسالة لرقم المكتب. سيرد «جاهز ✅»، وهذا يفتح نافذة الـ٢٤ ساعة لاستقبال الإشعارات. **كرّرها مرة كل يوم**، وإلا لن تصلك الأزرار (يمكن لاحقاً استبدال ذلك بقالب إشعار معتمد).
2. من رقم آخر أرسل رسالة للمكتب مثل: «كم سعر تجديد الإقامة؟». ستصلك الرسالة المقترحة بالأزرار.

## تعديل معرفة الوكيل
ملف `knowledge.json`: الخدمات والأسعار والمتطلبات والمدد. ما قيمته `null` يعني «يُحدد بعد المراجعة». أضف الأسعار هنا عند جاهزيتها، ويقرأها الوكيل مباشرة، ثم أعد النشر.

## الأمان
- التوقيع الأمني لكل رسالة من Meta يُتحقق منه، والرسائل غير الموقّعة تُرفض.
- المفاتيح في متغيرات البيئة فقط، ولا تُرفع إلى GitHub (موجودة في .gitignore).
- الوكيل لا يطلب كلمات مرور ولا رموز تحقق ولا بيانات بنكية، ولا يعالج صور الهويات.
