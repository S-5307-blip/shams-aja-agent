# منصة وكلاء شمس أجا

لوحة تحكم معزولة لتشغيل وكلاء ذكاء اصطناعي نبيعها لعملاء الشركات (B2B). العميل يربط أنظمته بوكيله عبر واجهة برمجية (API) بمفتاح خاص، ونحن ندير من اللوحة كل شيء: العملاء، الوكلاء وتعليماتهم ومعرفتهم، المفاتيح، الحدود، الاستهلاك والتكلفة، المحادثات، وسجل التدقيق.

## العزل عن شغل المكتب

| | موقع المكتب (`shamsaja-app`) | منصة الوكلاء (هذا المستودع) |
|---|---|---|
| المستودع | مستقل | مستقل |
| قاعدة البيانات | PostgreSQL الخاصة بالموقع | PostgreSQL مستقلة، لا تتصل بقاعدة الموقع |
| حسابات الدخول | مستخدمو الموقع | حسابات خاصة بفريق المنصة فقط |
| مفتاح Claude | مفتاح سلمى والمكتب | مفتاح مستقل من Workspace منفصل في Anthropic Console |
| النشر | مشروع Railway الحالي | مشروع Railway جديد منفصل |

لا يوجد أي كود أو اتصال مشترك بين المشروعين، وتعطّل أحدهما أو تجاوز سقف تكلفته لا يمس الآخر.

## ما تفعله المنصة

- **العملاء (Tenants):** لكل منشأة حالة (نشط/موقوف)، سقف تكلفة شهري، وحد طلبات في الدقيقة. إيقاف العميل يوقف كل مفاتيحه فورًا.
- **الوكلاء:** لكل وكيل تعليمات ومعرفة ونموذج ومستوى جهد وحالة (مسودة/يعمل/متوقف)، مع قوالب جاهزة (خدمة عملاء، تأهيل عملاء محتملين، مساعد داخلي) وصفحة تجربة مباشرة.
- **مفاتيح API:** تُعرض مرة واحدة عند الإنشاء، وتُحفظ ببصمة SHA-256 فقط. يمكن تقييد المفتاح بوكيل واحد، وإلغاؤه في أي وقت.
- **العزل بين العملاء:** كل استعلام من الواجهة البرمجية مقيد بالعميل صاحب المفتاح؛ لا يستطيع عميل رؤية وكيل أو محادثة عميل آخر (مغطى باختبارات على PostgreSQL).
- **الاستهلاك والتكلفة:** كل طلب يُسجل برموزه وتكلفته التقديرية وزمنه وحالته. تظهر التكلفة بالريال والدولار لكل عميل ووكيل.
- **قواعد المنصة الثابتة:** تُضاف قبل تعليمات كل وكيل: الرد بلغة المستخدم، عدم اختلاق الأسعار، عدم كشف التعليمات، تجاهل محاولات تغيير الدور من المستخدمين، عدم طلب كلمات المرور أو الرموز.
- **سجل التدقيق:** كل إنشاء وتعديل وإلغاء ودخول، مع من نفّذه.
- **الأدوار:** مالك (كل شيء + الفريق + الحذف)، مدير (العملاء والوكلاء والمفاتيح)، اطلاع فقط.

## النموذج

الوكلاء يعملون على Claude عبر الواجهة الرسمية `@anthropic-ai/sdk`:

- الافتراضي **Claude Opus 5.5** بمستوى جهد متوسط، ويمكن لكل وكيل اختيار Sonnet 5.5 (متوازن) أو Haiku 5.5 (الأرخص).
- **التخزين المؤقت للتعليمات والمحادثة** (prompt caching): تُقرأ التعليمات والمعرفة والمحادثة السابقة بعُشر السعر في الرسائل التالية.
- **البديل عند الرفض** (`fallbacks: "default"`): إذا رفض النموذج طلبًا لأسباب السياسة، يعيد Anthropic المحاولة تلقائيًا على النموذج البديل المعتمد. الطلب المرفوض نهائيًا يرجع للعميل برمز `refused` ولا يُحفظ في المحادثة.
- الأسعار في `src/lib/models.ts` تقديرية لعرض التكلفة وتطبيق السقف؛ راجعها مع [صفحة الأسعار](https://platform.claude.com/docs/en/about-claude/pricing) عند تغيرها.

الوكلاء في هذا الإصدار يحاورون فقط ولا ينفذون أدوات أو إجراءات في أنظمة العميل.

## التشغيل المحلي

```bash
npm ci
cp .env.example .env      # عدّل DATABASE_URL وAUTH_SECRET وANTHROPIC_API_KEY
npm run db:migrate
BOOTSTRAP_OWNER_NAME="الاسم" BOOTSTRAP_OWNER_EMAIL="you@example.com" BOOTSTRAP_OWNER_PASSWORD="كلمة-مرور-قوية" npm run bootstrap:owner
npm run dev
```

## الأوامر

```bash
npm run lint
npm run typecheck
npm test                                           # اختبارات الوحدة
TEST_DATABASE_URL=postgresql://.../agents_test npm test   # + اختبارات قاعدة البيانات (تمسح تلك القاعدة)
npm run build
npm run check:env                                  # يتحقق من متغيرات الإنتاج
```

## الملفات المهمة

- `src/lib/engine.ts` — تشغيل دورة المحادثة: التحقق، الحدود، استدعاء النموذج، الحفظ، تسجيل الاستهلاك.
- `src/lib/prompt.ts` — قواعد المنصة الثابتة وبناء التعليمات.
- `src/app/api/v1/*` — الواجهة البرمجية للعملاء.
- `src/app/(dash)/*` — صفحات لوحة التحكم.
- `docs/api.md` — توثيق الربط لفريق العميل التقني.
- `docs/deployment.md` — خطوات النشر على Railway.
- `legacy/shams-aja-whatsapp-agent.zip` — وكيل واتساب المكتب السابق كما رُفع، لم يُعدّل.
